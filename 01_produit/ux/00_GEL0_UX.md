# Gel 0 UX

> Version : **4.0.0**  
> Dernière mise à jour : **2026-08-24**  
> Propriétaire : **Responsable UX**  
> Statut : **FROZEN**

## Principe

L'interface doit permettre de **déclarer vite** et **traiter progressivement**.

## Navigation mobile primaire

Barre fixe à 4 destinations :

1. **Accueil**
2. **Registre**
3. **+ Nouveau**
4. **Analyse**

## Écrans secondaires

- Détail dossier : ouvert depuis Accueil/Registre/Analyse.
- Mes dossiers : filtre enregistré du Registre, accessible depuis Accueil.
- Administration : dans menu utilisateur, admin seulement.
- Révisions dues : sous-vue Analyse.

Ils ne créent pas de 5e/6e destination principale.

## Breakpoints

- mobile : 320–767 px
- tablette : 768–1023 px
- desktop : ≥1024 px

La logique et l'ordre des informations ne changent pas selon breakpoint.

## Convention CTA

Un seul CTA primaire visible par zone.

Exemples :
- Nouveau : `Enregistrer le dossier`
- Détail : `Enregistrer`
- Résolution : `Régler le dossier`

Les actions secondaires sont visuellement secondaires.
